# Running notes

A living log while I build this project. Capture:

- **What I did** — the actual commands/steps, not the idealized version.
- **What broke** — errors, dead ends, and how I got unstuck. This is the most valuable part.
- **What I learned** — the concept that finally clicked.
- **What I'd do differently** next time.

> Dated entries work well. These notes become the raw material for the project write-up and for interview stories.
